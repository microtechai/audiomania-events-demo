# Estructura de Páginas - Audiomania Eventos

## Páginas Principales

### 1. Home (/)
- **Tipo:** Página de inicio con Elementor
- **Secciones:**
  1. Hero con slider de servicios (parallax + GreenShift)
  2. Servicios destacados (cards con hover effects)
  3. Sobre nosotros (breve + foto equipo)
  4. Estadísticas (contadores animados)
  5. Testimonios (carrusel)
  6. Galería de eventos (masonry grid)
  7. CTA de reserva + WhatsApp button
  8. Footer con datos de contacto

### 2. Servicios (/servicios/)
- **Tipo:** Listado de servicios con Elementor
- **Secciones:**
  1. Header de página
  2. Grid de servicios (7 cards)
  3. Cada card: imagen + título + descripción breve + enlace
  4. CTA "Solicitar presupuesto"

### 3. Reservar (/reservar/)
- **Tipo:** Página de reservas + WooCommerce
- **Secciones:**
  1. Formulario de reserva (WPForms o similar)
  2. Catálogo de productos WooCommerce
  3. Proceso de pago Stripe
  4. FAQ de reservas

### 4. Galería (/galeria/)
- **Tipo:** Galería de imágenes con Elementor
- **Secciones:**
  1. Filtros por tipo de evento (bodas, corporativos, etc.)
  2. Grid de imágenes con lightbox
  3. Integración con GreenShift Gallery

### 5. Contacto (/contacto/)
- **Tipo:** Página de contacto
- **Secciones:**
  1. Formulario de contacto
  2. Mapa de ubicación
  3. Datos de contacto (teléfono, email, WhatsApp)
  4. Horario de atención

### 6. Sobre Nosotros (/sobre-nosotros/)
- **Tipo:** Página institucional
- **Secciones:**
  1. Historia de la empresa
  2. Equipo (opcional)
  3. Valores y diferenciales
  4. Certificaciones y partners

## Páginas WooCommerce
- **Tienda:** /tienda/ (Catálogo de productos)
- **Carrito:** /carrito/ (Carrito de compras)
- **Pago:** /finalizar-compra/ (Checkout con Stripe)
- **Mi Cuenta:** /mi-cuenta/ (Área de cliente)
- **Políticas:** /politica-de-reembolso/ /politica-de-privacidad/
